# A Guide to the Miniproject

Hi! This is my miniproject!

Here is a neat guide to the files:

These notebooks all run different Markov chains. They are separate notebooks so they can be run simultaneously.
| File Name | Starting Point | 2024 Data? | Data File |
| -------- | -------- | -------- | --------|
| miniproject.ipynb    | Random   | No   | markov_chain_output2.json |
| miniproject random run.ipynb    | Random   | Yes   | markov_chain_output_RANDOM.json |
| miniproject prop50 run.ipynb    | Prop 50 Plan   | Yes   | markov_chain_output_PROP50.json |

Please note, miniproject random run.ipynb was run twice but all the data is contained in markov_chain_output_RANDOM.json. Because I used a random seed, the data is duplicated, so analysis was performed after removing the first 5,200,000 data points.

All the analysis can be found within analysis.ipynb. It is separate from the others to prevent massive files and because loading the data into multiple variables can crash the kernel. It is over 4 gb of data, after all. 

The figures generated by analysis.ipynb can all be found as .png files within this folder. The other files not mentioned are shapefiles or data files that were retrieved from the internet. Data was retrieved from the Census website and the California Redistricting Statewide Database at https://statewidedatabase.org/.
